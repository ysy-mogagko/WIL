# 학습 내용

## 기본 값 확인

` container system property list`

## apple container kernel build

- `git@github.com:apple/containerization.git` repo를 사용
- `make`를 통하여 빌드
- `bin/` 내용 확인

## kernel apply

- 일회성

```
container run --rm \
  --kernel {abs-vmlinux-path} \
    {container-image}
```

- 기본 값 변경

```
container system kernel set --arch {target-arch} --binary {abs-vmlinux-path}

```
